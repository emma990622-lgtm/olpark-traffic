# 관객 화면 첫인상 다듬기 (불러오는 중·빈 칸 처리)

## 왜 하나요
- 데이터를 불러오기 전이나 실패했을 때 "불러오는 중…"이 그대로 남거나 빈 칸이 보여서, 심사위원이 처음 열었을 때 고장 난 것처럼 보일 수 있다.
- 로컬 실행처럼 `/api`가 없는 환경에서도 화면이 자연스러워야 한다.

## 바꿀 것
- [코딩] 지도·도로 정보·도보 시간·요금을 불러오는 동안과 실패했을 때의 상태를 구분해서 표시한다 (불러오는 중 / 아직 자료 없음 / 실시간 연결 안 됨). 상태마다 class를 붙인다.
- [코딩] 날짜·공연 목록이 비어 있을 때(예정 공연 없음) 안내 문구를 보인다.
- [디자인] 위 상태들을 위한 스타일(스켈레톤 또는 옅은 안내 상자), 상태 문구가 색만이 아니라 아이콘·글자로도 구분되게.
- [디자인] 360px 폭에서 단계 번호(1·2·3)와 제목 간격, 카드 여백을 정리한다.

## 화면
- 관객 화면 (index.html)

## 끝났다고 볼 기준
- `/api`가 없는 로컬 실행에서도 "불러오는 중…"이 영원히 남는 곳이 없다.
- 360px 폭에서 가로 스크롤이 생기지 않는다.

## 하지 말 것
- 운영자 화면은 건드리지 않는다.
- 데이터 계산 방식(요금, 도보 시간)은 바꾸지 않는다.
