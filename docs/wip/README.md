# 작업 중 표지판 (`docs/wip/`) — AI 동시 작업 방지

`docs/handoff/`가 **끝난 일** 기록이라면, `docs/wip/`는 **지금 작업 중인 일**을 알리는 표지판이다.
별도 서버나 도구 없이, 모든 AI(Claude·Antigravity·Codex)가 저장소 파일만 보고 동시 충돌을 막는다.

## 사용 규칙 (딱 3단계)
1. **시작 전 확인**: `git pull` 직후 이 폴더에 `README.md` 외의 `.md` 파일이 있는지 본다.
   - **90분 이내**에 만든 파일이 있으면 **작업을 시작하지 않고 멈춘 뒤** 사용자에게 누가 어떤 파일을 만지는 중인지 알린다. (사용자가 "겹치지 않으니 진행해"라고 하면 진행)
   - **90분이 지난** 파일은 중단·미삭제 잔여물로 보고 사용자에게 확인 뒤 정리한다.
2. **찜하기 (시작 시)**: 비어 있으면 새 파일 `docs/wip/YYYY-MM-DD_HHMM_누가_요약.md`를 만들고, **이 파일 1개만 먼저 커밋·push**한다(`[WIP] 누가 요약 시작`).
3. **해제 (끝날 때)**: 작업 완료 커밋(`docs/handoff/` 노트 포함)에서 **내가 만든 `docs/wip/` 파일을 삭제**한다.

## 파일 양식 (4줄)
```markdown
- 누가: (AI 이름 + 사람, 예: antigravity-주인)
- 시작 시각: YYYY-MM-DD HH:MM KST
- 할 일: 한 줄 요약
- 만질 파일: web/index.html, web/assets/audience.js
```
