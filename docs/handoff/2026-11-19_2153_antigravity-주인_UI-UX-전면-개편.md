# UI/UX 전면 개편 (KRDS 기반 + Toss·Citymapper·카카오T 패턴)

- 날짜·시각: 2026-11-19 21:53
- 누가: Antigravity(Gemini) + 저장소 주인
- 관련 Issue/PR: PR #2 (`ui/krds-toss-redesign`). 이 노트는 PR #2 설명을 새 인수인계 노트 양식으로 옮긴 것.

## 요청 해석
- 한국체육산업개발 공공데이터 활용 경진대회 출품작의 성격(공공 신뢰성 + 모바일 관객 의사결정 + PC 운영자 현장 관제·브리핑)에 잘 어울리는 검증된 UX/UI 레퍼런스를 결합해 두 화면을 전면 다듬어 달라는 요청으로 이해했습니다.
- 여러 AI 에이전트(Claude Code, Antigravity, Codex)와 팀원이 함께 작업하므로, 새로 정한 디자인 토큰·클래스 이름·보호 식별자가 끊기지 않도록 공식 디자인 문서(`docs/design.md`)와 배경 결정 기록(`docs/context.md`), 그리고 이 PR 인수인계서를 명확히 남기는 것을 핵심 조건으로 잡았습니다.

## 바꾼 것
- `web/assets/style.css`: KRDS(디지털 정부서비스 UI/UX 가이드라인) 기반 `:root` 변수 체계 확장, `Pretendard` 타이포그래피·`tabular-nums` 숫자 정렬·`keep-all` 줄바꿈 적용, 모든 인터랙티브 요소 최소 높이 `44px`(`--tap-min`) 및 WCAG AA 명도 대비 `4.5:1` 이상 보정(지하철 노선 배지·보조 텍스트 포함), 반응형 테이블(`.table-scroll`) 및 A4 인쇄(`@media print`) 양식 정돈
- `web/index.html`, `web/assets/audience.js`:
  - `Pretendard Variable` 다이나믹 서브셋 CDN 연결 및 상단 고정 헤더·모드 전환 탭 정돈
  - Step 1 선택 공연 요약 카드(`.event-summary`, `.stat-strip`) 도입 및 다회차 공연일(`12/24` 등) 회차 수 병기(`공연 1개(3회)`)
  - Step 3 각 주차 선택지 상단에 **Toss 스타일 핵심 3지표 요약 스트립(`.opt-metrics`)** 추가
  - 공원 안 주차장에 **카카오T 주차 스타일 실시간 보정 잔여면·점유율 게이지 박스(`.live-lot-box`, `.occ-bar`)** 적용 (`parkActual()` 장기 주차 차감 근거 명시 유지)
  - 환승주차(`공연장 갈 때` / `공연장에서 나올 때`) 카드를 **Citymapper 스타일 이동 단계 알약 칩(`.route-steps` > `.step-pill`)** 구조로 개선하고, 공모전 심사 기준에 맞춰 `'공원 정체를 피하는'` 문구를 **`'출구 혼잡을 덜어 주는 분산 주차'`**로 순화
  - 대중교통 탭 역 목록에 호선별 색상 배지(`.line-badge`) 및 최단 도보 역 강조 추가
- `web/operator.html`, `web/assets/operator.js`:
  - 상단 점검 필터 바(`.filter-bar`) 및 상태 컬러 상단 보더 핵심 KPI 4종(`.kpi`) 정돈
  - `roadCheck` 실시간 도로 자료 교차검증 박스를 `.verify-box` + `<ol>` 자동 번호 구조로 바꿔 중간 항목 부재 시 `① → ③`으로 번호가 건너뛰던 표시 오류 수정
  - 3D 지도 카드에서 실시간 모드일 때 `#tInfo`와 `#roadNote`에 동일 기준 시각 문구가 중복 출력되던 현상 정리
  - 출구별 대응 표(`#gateTable`)에 차량 비중 미니 바(`.share-cell`, `.share-bar`) 추가 및 `동2문` 등 출구명 줄바꿈 방지(`.nowrap`)
  - 5분 단위 히트맵(`#heat`) 첫 열 고정(`sticky`) 및 셀 `title`·`aria-label`에 혼잡 단계 텍스트 병기, 기관 공유용 1장 요약표(`.brief`) 가독성 개선
- `web/assets/common.js`, `web/assets/map3d.js`:
  - `levelOf()`에 상태 기호(`●`/`▲`/`○`) 추가 및 `lineBadgesHTML()` 도우미 추가, 지도 범례에 색상+기호+글자 동시 표기
  - 3D 지도 초기 줌을 화면 폭에 맞춰 미세 조정(`14.72` / `14.98`)해 기본 화면에서 외곽 마커(`한성백제박물관`, `올림픽공원역` 등)가 테두리에 잘리던 현상 완화
- `docs/design.md` (신규), `docs/context.md`:
  - `:root` 변수 규격, **JS↔CSS 클래스 계약표**, 보호 대상 HTML `id`·`data-*` 목록, 공모전 표현 체크리스트를 `docs/design.md`에 문서화하고 `docs/context.md` 결정 기록에 반영

## 결정과 이유
- **투트랙 통일 디자인 시스템 채택 (`docs/design.md`, `docs/context.md` 기록 완료)**: 공공데이터 경진대회 심사위원에게 신뢰를 주는 KRDS 접근성·타이포 기준을 공통 골격으로 삼고, 모바일 관객 화면은 빠른 선택을 돕는 Toss·Citymapper·카카오T 카드 패턴을, PC 운영자 화면은 관제 대시보드 패턴을 결합했습니다.
- **환승주차 표현을 `'회피'`에서 `'분산'`으로 변경**: 한국체육산업개발 출품작 특성상 공원 주차장 이용을 피하라고 권하는 뉘앙스 대신 `'출구 혼잡을 덜어 주는 분산 주차'`로 표현해 기관 입장과 부합하게 다듬었습니다.
- **외부 빌드·라이브러리 미추가 원칙 유지**: `GEMINI.md`에서 허용한 `Pretendard Variable` 다이나믹 서브셋 CDN만 추가하고 순수 HTML/CSS/JS 구조를 그대로 유지했습니다.
