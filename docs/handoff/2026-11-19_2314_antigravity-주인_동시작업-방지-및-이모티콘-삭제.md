## 결정과 이유
- **저장소 안 `docs/wip/` 표지판 방식 선택**: 별도 서버·구글 시트 없이도 네트워크가 제한된 클라우드 Codex와 로컬 Claude·Antigravity가 모두 동일한 파일을 읽어 동시 작업을 막을 수 있고, 작업당 파일 1개 구조라 표지판 자체에서 git 충돌이 나지 않기 때문.
- **90분 만료 기준**: 에이전트 중단 등으로 표지판이 지워지지 않았을 때 영구 잠금이 걸리지 않게 90분 경과 파일은 미삭제 잔여물로 안내하도록 정함.
