## 결정과 이유
- 인수인계를 PR 설명이 아니라 **저장소 안 파일(`docs/handoff/`)**로 남긴다. main에 바로 올리는 방식에는 PR이 없고, 어떤 AI든 파일은 읽을 수 있기 때문.
- 노트를 한 파일에 이어 쓰지 않고 작업마다 새 파일로 만든다. 같은 파일 맨 위에 둘이 동시에 쓰면 매번 충돌이 나기 때문.
- main 보호 규칙(직접 push 금지)은 걸지 않는다. 도로 검증 자동 실행이 결과를 main에 저장하고, 바로 반영 방식과도 맞지 않기 때문.
