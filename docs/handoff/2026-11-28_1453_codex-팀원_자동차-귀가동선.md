# 자동차 귀가 동선 단축

- 날짜·시각: 2026-11-28 14:53 KST
- 누가: Codex-팀원
- 관련 Issue/PR: 자동차 귀가 동선 변경 PR

## 요청 해석
자동차 선택 뒤 안내 선택 단계를 없애고 바로 주차 위치를 선택. 방면 선택 뒤 결과 상단에서 귀가 안내와 주변 도로 전환.

## 바꾼 것
귀가 안내를 기본 결과로 표시하고 두 버튼으로 전환. 자동차 도착 그래프 진입은 결과 아래에 배치. 대중교통의 지도·도착 메뉴는 기존 화면을 사용.

## 확인한 방법
`scripts/check_all.py` 통과. 360px 로컬 브라우저에서 주차 위치 바로 진입, 방면 선택·생략, 세 출구 결과 유지, 지도·도착 그래프, 이전 이동 및 대중교통 역 목록 확인.

## 결정과 이유
결과 버튼을 전환할 때 주차·방면 상태를 다시 초기화하지 않고 키보드 포커스를 버튼에 유지.

## 건드리면 안 되는 것
`data-car-view` 버튼 상태와 `data-journey` 화면 연결, 기존 출구 계산 및 지도 스크립트.

## 다음 사람에게 넘길 일
배포 뒤 모바일 브라우저에서 사용 흐름 확인.
