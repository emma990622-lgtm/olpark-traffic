# 관객 화면 지도 글씨·이름표 겹침·저작권 표시 가림 수정

- 날짜·시각: 2026-11-25 17:20
- 누가: Claude(Opus 5.5) + 주인
- 관련 Issue/PR: 없음

## 요청 해석
- "지도 글씨와 겹침 문제는 고쳐줘" → 11/25 실제 사이트(360px) 점검에서 찾은 3가지: ① 3D 지도 'P 공원 주차장' 이름표가 '우리금융아트홀' 이름표 위에 겹침, ② 지도 저작권 표시가 펼쳐진 채 지도 아래 약 1/4을 가리고 ⓘ가 두 개로 보임, ③ '평면 지도' 글씨가 휴대폰에서 약 4~5px로 읽을 수 없음.
- 같은 대화에서 주인이 "숫자의 출처와 기준은 다 지울 것"이라고 함 → 출처 칸(`egSrc`, `vfSrc`, `eventInfo`)은 이번에 건드리지 않음.

## 바꾼 것
- `web/assets/map3d.js`: `declutter()` 추가 — 화면에서 겹치는 이름표를 중요도 낮은 것부터 숨김(KSPO DOME > 내 위치 > 지하철역 > 공원 주차장 > 다른 주차장 > 다른 공연장). 지도 이동·확대·크기 변경, 공연장 바꾸기, 내 위치 표시 때 다시 계산. 저작권 표시는 접힌 ⓘ로 시작(누르면 펼쳐짐).
- `web/assets/park-web.css`: `.park-web details summary { min-height:48px; padding:14px 0 }` 규칙이 MapLibre 저작권 버튼(`summary`)에도 걸려 48px로 늘어나 ⓘ 아이콘이 두 번 그려지던 문제 → 저작권 버튼만 24px로 제외.
- `web/assets/common.js` `drawRoadMap()`: 화면에 보이는 폭으로 글씨·점·선 굵기를 계산(글씨 약 12~14px). `ResizeObserver`로 숨겨져 있다가 보이거나 폭이 바뀌면 다시 그림. 이름끼리 겹치면 위→아래→오른쪽→왼쪽 자리를 찾고, 없으면 이름만 빼고 점은 남김. 글씨에 흰 테두리(paint-order)로 선 위에서도 읽히게.
- `web/index.html`: 캐시 번호(`common.js`·`map3d.js` ped2, `park-web.css` v4).
- `docs/design.md`: 3D 지도 줄에 이름표 정리·ⓘ·평면 지도 규칙 추가.

## 확인한 방법
- 평면 지도: 로컬 Playwright 360px·1280px — 글씨 높이 14px(이전 360px에서 약 4.6px), 페이지 오류 0. 360px에서는 겹치는 '한성백제박물관'·'회관 외' 이름이 빠지고 점은 남음.
- 3D 지도: 실제 사이트(배포 후) 360px — 저작권 접힘, '우리금융아트홀'·'핸드볼경기장'·'남3문' 이름표가 겹쳐서 숨겨지고 'P 공원 주차장 · 6분'이 깨끗이 보임. 콘솔 오류 없음.
- `python scripts/check_all.py` ✅

## 결정과 이유
- 이름표를 지우지 않고 겹칠 때만 숨김 → 확대하면 다시 나타남.
- 중요도는 관객이 길을 찾는 데 쓰는 순서(공연장·역·내 주차장)로.

## 건드리면 안 되는 것
- `.m3d` 클래스 이름(`dome`·`me`·`st`·`lot`·`venue`) — `declutter()`의 중요도 판단에 씀. 'P 공원 주차장' 글자도 공원 주차장 판단에 씀.
- `svg._mapArgs`·`svg._mapRO`(평면 지도 다시 그리기용).
