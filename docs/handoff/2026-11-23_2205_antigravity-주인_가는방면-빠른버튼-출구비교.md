# 상용 API 호출 없는 '가는 방면 빠른 버튼' 출구별 총 소요 시간 비교 추가

- 날짜·시각: 2026-11-23 22:05
- 누가: Antigravity + 주인
- 관련 Issue/PR: 없음

## 요청 해석
- 공공기관 운영 시 TMAP·네이버 등 민간 길찾기 API는 유료 전환될 우려가 있으므로 런타임 길찾기 API를 일절 호출하지 않는다.
- 대신 **'가는 방면 빠른 버튼'** 형식으로 공원 둘레 도로의 공연 직후 실측 주행 시간을 미리 계산해 저장(`web/data/gate_directions.json`)하고, 추가 API 호출 없이 주차한 곳과 가는 방면을 합산해 어느 문으로 나가는 것이 가장 빠른지 안내한다.

## 바꾼 것
- `scripts/29_gate_directions.py`, `web/data/gate_directions.json` (새 파일):
  - 세 출구(`북2`·`동2`·`남2`문)에서 나온 차량이 같은 방면으로 갈 때는 공원 둘레의 같은 합류 교차로(`올림픽대교남단교차로`, `평화의문(몽촌토성역) 교차로`, `올림픽공원사거리(남동측)`, `둔촌사거리`)에서 만나 그 이후 시간은 서로 상쇄된다는 성질을 이용함.
  - 서울시 실시간 도시데이터(OA-21285) 도로 구간 길이(`links.json`)와 수집기(`olpark-collector`)가 실제 KSPO DOME 공연 종료 출차 집중 시간대(`2026-11-21` 20:45~22:15, `2026-11-22` 19:45~21:15, 5분 간격 39회 시점)에 측정한 구간별 속도 중앙값으로 4개 방면 × 3개 출구의 둘레 도로 주행 시간을 계산해 저장함.
- `web/index.html`, `web/assets/exit_gate.js`, `web/assets/style.css`:
  - `3 공연 끝나고 어느 문으로 나갈까요?` 카드에 **'어느 방면으로 가시나요?'** 빠른 버튼(`#egWay`: `방면 선택 안 함` + 북서·북동·남서·남동 방위 순서 4개 버튼) 추가 (`style.css?v=7`, `.eg-zones button.span-all`).
  - 방면을 고르면 `공원 안 출구 통과 차이(exit_gate.json)` + `출구→합류 교차로 둘레 도로 시간(gate_directions.json)`을 합산해 추천 출구와 비교 표(`공원 안` / `합류점까지` / `합계 비교`)를 표시함.
  - 1·2위 합계 차이가 1분 미만일 때(예: `동2` 구역 주차 + `올림픽대교·강북` 방면 `북2문` 4.0분 vs `동2문` 4.5분)는 과장하지 않고 **`● 거의 비슷해요`** 로 안내함.
- `web/data-guide.html`, `docs/design.md`, `docs/context.md`:
  - `gate_directions.json` 파일 설명·변수 표, 보호 `id`(`egWay`), 결정 기록 추가.

## 확인한 방법
- `python3 scripts/29_gate_directions.py` 실행: 수집 시점 39회·도로 구간 24개 기준으로 `web/data/gate_directions.json` 정상 생성 확인.
- `python3 scripts/check_all.py` 실행: JS 13개·파이썬·JSON·보호 `id` 검사 오류 0건, 경고 0건 확인.
- 360px 모바일 폭 Playwright 시험: `#egWay` 5개 버튼 모두 높이 44px 이상 확인, `북2 + 잠실·강남` / `동2 + 올림픽대교` / `그 밖의 주차장 + 송파·분당` 조합 렌더링 확인, 가로 넘침 `0px` 및 외부 상용 API 호출 `0건` 확인, `data-guide.html` 반영 확인.

## 결정과 이유
- 민간 유료 API 의존을 완전히 배제하고 **한국체육산업개발 차량 이용현황 + 서울시 실시간 도시데이터(TOPIS)** 공공데이터 두 가지만 결합해 재현 가능하고 영구 무료인 정적 JSON 구조로 설계함.
- 분석 결과 `북2문(P4·P5)` 주차 후 반대편(`잠실·강남`, `송파·분당`)으로 가더라도 공원 안을 가로질러 `동2문`·`남2문`으로 나가는 것보다 **`북2문`으로 바로 나가 공원 바깥 큰길로 도는 쪽이 빠르다**는 점이 수치로 확인되어, 내부 정체 분산 유도 근거로도 활용 가능함.
