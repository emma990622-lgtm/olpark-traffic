## 요청 해석
사용자가 확인한 최종 시안을 최신 olpark-traffic 코드에 적용. 별도 브랜치에서 검토하기로 한 범위에 맞춰 초안 PR로 전달.

## 바꾼 것
- 공연 → 이동수단 → 안내 선택. 자동차는 주차 위치·방면을 거쳐 세 출구를 비교하고, 지도와 도착시간 그래프는 별도 화면에서 표시.
- 화면 전환 효과, ALL PARK 헤더, 명사형 문구 반영. 날씨·GPS·3D/평면 지도 연동과 기존 데이터는 보존.
- 로딩 전 공연 목록이나 도로 자료가 없을 때 상태를 표시.

## 확인한 방법
- `scripts/check_all.py` 통과, JS 14개·경고 0개. `git diff --check` 통과.
- 로컬 브라우저 360px에서 공연 선택·자동차·주차 위치·방면·세 출구·수동 날씨·뒤로 가기·3D 지도·그래프·대중교통 확인. 가로 넘침 없음.
- 로컬 정적 서버는 Vercel 환경변수와 운영 API를 사용하지 않으며, 실기기 GPS 권한은 확인하지 않음.

## 결정과 이유
HTML 공유용 정적 파일 대신 공식 배포가 사용하는 web 소스를 변경. 자동 병합 워크플로가 적용되는 일반 PR은 검토가 끝난 뒤 전환.
