# 관객 화면·데이터 설명서 내 문구 불일치 및 예보·기호 표기 정리

- 날짜·시각: 2026-11-23 11:45
- 누가: Antigravity + 주인
- 관련 Issue/PR: 없음

## 요청 해석
- 출품 대상 서비스 주소는 `https://olpark-traffic.vercel.app`이며, 기관은 공연안전지원센터·안전관리 전문 대행업체 등 자체 소통·현장 자료가 더 많으므로 **관객 전용 서비스**로 계속 진행한다.
- 라이브 관객 화면(`web/index.html`)과 연결된 결과 데이터 설명서(`web/data-guide.html`) 안에 남아 있는 앞뒤 불일치·구버전 문구를 해결한다.

## 바꾼 것
- `web/index.html` (`#vfWx`): 방문객 혼잡 예측 카드의 날씨 선택 문구를 `예보 사용(16일 앞까지)` → `공연 날 예보 사용(24시간 앞까지)`로 고침 (`visitor.js`가 서울시 실시간 도시데이터 24시간 예보를 쓰며, 바로 위 `#egWx`와도 표현 통일).
- `web/assets/audience.js`:
  - `today` 계산을 UTC(`new Date().toISOString()`)에서 한국 표준시(`Date.now() + 9 * 3600e3`)로 고쳐 한국 시각 00:00~08:59에 전날 끝난 공연이 첫 항목으로 잡히는 문제를 막음.
  - `#reco` 하단 설명의 시제품 시절 문구(`"2025년 입출차 데이터로 만든 예측이 연결되면 시간까지 계산해 드려요"`)를 실제 화면 구성에 맞게 `"이날 공원 전체 공연 좌석 규모 기준 안내예요. 지난 공연 기록으로 계산한 예상 만차·출차 소요 시간은 아래 선택지에서 함께 확인해 보세요."`로 고침.
  - KSPO DOME이 아닌 공연장을 골랐을 때 나오던 `"이 공연장의 출차 기록은 2025 데이터로 채울 예정이에요"` / `"준비 중"` / `"2025 데이터 예정"`을 `"출차 소요 통계는 KSPO DOME 공연 기준으로만 있어요"` / `"아직 없음"` / `"KSPO DOME만 계산"`으로 바로잡음.
  - 선택 2(공원 바깥쪽 주차장) '귀가할 때'의 `"공연일 실측으로 확인 예정"`을 `exit_gate.json`(`otherLots`) 사실에 맞춰 `"동2·북2·남2문 안쪽 주차장과 길이 이어지지 않아 들어온 문으로 바로 나가요(출차 소요 시간은 아직 없음)."`으로 고침.
  - 선택 3(환승주차 나올 때) 각주의 지난 날짜 문구(`"11/21·22 공연일 현장 실측으로 보정할 예정이에요"`)를 `"가정값이라 실제 대기 시간과 다를 수 있어요."`로 정리함.
- `web/assets/common.js` (`levelOf`): 혼잡 수준 배지 기호를 `집중 ● / 주의 ▲ / 평소 ○` → `집중 ■ / 주의 ▲ / 평소 ●`로 고쳐 화면 내 다른 모든 카드·범례(`여유/원활 ●`, `보통/서행/붐빔 ▲`, `혼잡/정체/매우 붐빔 ■`)와 일치시킴.
- `web/data-guide.html`: 문서 제목을 `올팍 공연 주차·귀가 안내 · 결과 데이터 설명서`로 맞추고, 원천 데이터 요약·파일 목록 표(`exit_gate.json` 추가, `kspo_waves.json` 차량 이용현황 173회 반영, `events.json` 자동 수집 스크립트 `28, 02, 27` 반영)·주요 변수(`weather.effectTour.wet, cold` 추가)·유의사항(차량 이용현황 기반 파일과 2025 입출차 보정 파일 구분)을 최신 화면과 일치시킴.
- `scripts/check_all.py`, `docs/design.md`: `visitor.js ↔ index.html` id 검사 쌍과 `#visitorCard` 관련 보호 `id` 6개를 점검 대상에 추가함.
- `README.md`, `AGENTS.md`, `docs/deploy_vercel.md`, `docs/context.md`: 운영자 화면 보관(`archive/operator/`) 이후 남아 있던 두 화면 표기를 현재 관객 전용 배포 기준으로 맞춤.
