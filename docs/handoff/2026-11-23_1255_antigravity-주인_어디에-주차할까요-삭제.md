# 관객 화면에서 '어디에 주차할까요?' 섹션 삭제 및 3단계 출구 안내 연결

- 날짜·시각: 2026-11-23 12:55
- 누가: Antigravity + 주인
- 관련 Issue/PR: 없음

## 요청 해석
- 공연하러 갈 때(입차 시간대)는 실제로 주차와 관련된 문제가 없었으므로, 관객 화면(`web/index.html`)의 `'어디에 주차할까요?'`(`#carSection`) 부분을 삭제한다.
- 차로 오는 관객에게는 공연·이동 수단을 고른 뒤 바로 귀가 출구 안내(`'공연 끝나고 어느 문으로 나갈까요?'`)가 이어지도록 단계 번호와 전환 동작을 맞춘다.

## 바꾼 것
- `web/index.html`:
  - `<section class="card" id="carSection">` (`3 어디에 주차할까요?`, `#reco`, `#options`, `#subwayNote`, 요금 각주) 전체 삭제.
  - `#transitSection` (`3 가까운 역`) 하단에 `<p class="footnote">도보 시간 기준: <span id="walkSrc"></span>.</p>`를 옮겨 대중교통 역 도보 시간의 출처 표시를 유지함.
  - `#exitGate` 제목 단계 배지를 `4` → `3`(`3 공연 끝나고 어느 문으로 나갈까요?`)으로 고쳐 `차로 와요` / `대중교통으로 와요` 양쪽 모두 `1 → 2 → 3` 순서가 되게 함.
- `web/assets/audience.js`:
  - `#carSection` 전용으로만 쓰던 추가 데이터 호출(`exits_2024_07.json`, `kspo_waves.json`, `exit_profile.json`, `station_drive.json`, `congestion_summary.json`, `audience_car.json`, `/api/subway`, `/api/drivetime`, `loadParkNight`)과 렌더링 함수(`renderCar`, `transferGo`, `transferOutHTML`, `driveOn`, `lotFreeChip`, `tMode`)를 제거함.
  - `#eventInfo`에서 관람시간 안내가 없을 때 붙던 `"아래 주차·출차 계산은 공연 시간을 150분으로 가정했어요."` 문구를 제거함(해당 계산을 쓰던 `#carSection`이 없어짐).
  - `#mode` 버튼 클릭 시 `$("exitGate").hidden = b.dataset.v !== "car"` 및 `$("transitSection").hidden = b.dataset.v !== "transit"`로 바로 전환하도록 고침.
- `web/assets/exit_gate.js`:
  - 삭제된 `#carSection`을 감시하던 `MutationObserver`를 제거하고, 초기 로드 시 활성 `#mode button.on` 기준으로 `#exitGate.hidden`을 맞추도록 정리함.
- `docs/design.md`, `docs/context.md`:
  - 클래스 계약표와 보호 `id` 목록에서 `carSection`, `reco`, `options`, `subwayNote`, `data-tmode`를 빼고 3단계 구성을 반영함(`style.css`와 `common.js`의 공용 함수·스타일은 보관된 운영자 화면 등을 위해 그대로 유지).

## 결정과 이유
- 현장 관찰에서 입차 시 주차 부족·정체 문제가 없었으므로 불필요한 주차장 선택·환승주차 비교 카드를 덜어 내고 핵심 주제인 공연 종료 후 주차 구역·날씨별 빠른 출구 안내에 집중함.
- 역 도보 시간(`약 N분`)은 여전히 `#transitSection`에 표시되므로 출처 표시 원칙(`AGENTS.md`)에 따라 `#walkSrc` 각주는 `#transitSection`으로 옮겨 유지함.
