# 4단계 결과: 사용할 데이터와 범위 (2026-11-17)

## 한 줄 요약
**"공연이 끝나면 어느 출구로 차가 몇 대 빠져나가고, 그 앞 도로가 얼마나 막히는가"**를 보여주려면
① 2025년 입출차(게이트별) ② 공연 일정 ③ 5분 단위 실시간 도로 수집, 이 세 가지가 핵심이다.
2024년 7월 자료는 이미 분석해 봤고 "공연 날 밤에 출차가 확 몰린다"는 걸 확인했다(시제품용).

## 2. 실제로 쓸 필드

- **A**: 입차일시, 출차일시 → 15분 단위 입차·출차 대수, 체류 시간
- **B**: 입구, 입차시간, 출구, 출차시간 → **출구별** 15분 출차 대수
- **C**: 주차대수, 방문객, 기온, 강수량, 휴일, 공연명, 공연관람객수
- **D**: 날짜, 공연장, 공연명, 시작시각, (공연장 좌석규모 참고값)
- **E**: parking_sum = 현재 주차된 차량 수 (공원 전체 합계, 2026-11-18 확인. 장기 주차 차량 포함 가능)
- **F**: LINK_ID, 도로명, 속도(SPD), 혼잡도(원활/서행/정체), 수집 시각
- **G**: 일자, 링크아이디, 도로명, 방향, ~01시 … ~24시 속도

## 3. 지금까지 알게 된 것

1. **공연 날 밤 출차 몰림이 뚜렷하다** (2024-07, 15분 최대 출차 대수)
   - 평일 보통: 160~210대, 그것도 **아침**에 최대
   - 7/20 SG워너비: **376대** (21:15), 7/21: **391대** (20:30), 7/14 THE BOYZ: 300대
2. **시간 단위 도로자료(G)로는 효과가 흐릿하다.** 올림픽공원 주변 전체 평균은 공연날에도 거의 차이 없음.
   구간별로 보면 보인다: 7/12 22~23시 강동대로(북1문→올림픽대교남단) 14.4km/h, 같은 요일 평소 24.1km/h.
   → **5분 단위 실시간 수집(F)과 출구별 출차(B)가 왜 필요한지의 근거.**
3. 실시간 도시데이터 58구간 중 TOPIS에 있는 건 14구간뿐 → 골목·진출입로는 실시간 수집으로만 확보 가능.
