관객 안내

받는 방법

이 사이트의 분석 결과는 모두 JSON 파일로 공개돼 있어요. 사이트 주소 뒤에 /data/파일이름을 붙이면 받을 수 있어요. 예: https://olpark-traffic.vercel.app/data/exit_gate.json

원천 데이터: 한국체육산업개발 올림픽공원 차량 이용현황(2024년 3월~2025년 12월)·입출차 정보(2024년 7월, 2025년)·실시간 주차현황·주차장 혼잡도·공식 공연 일정, 서울시 실시간 도시데이터·생활인구·지하철 승하차·공영주차장 실시간 정보, 기상청 지상관측(ASOS), TMAP 보행·운전 경로. 계산 코드는 GitHub 저장소의 scripts/에 있어요.

출처·방법각 파일 안의 source, method에 문장으로 적혀 있어요.

쓸 때 알아 둘 것

  • 차량 이용현황으로 만든 파일(exit_gate.json, kspo_waves.json)은 빠진 달·보정이 없어요. 2024년 3월~2025년 12월 KSPO DOME 공연 173회 전체 기록이에요.
  • 2025년 입출차로 만든 파일의 대수는 보정한 값이에요. 받은 비율(달별 67~88%)로 나눈 뒤 반올림했고, 원본이 잘렸거나 시간대 기록이 모자란 8·9월과 10~12월 일부 공연은 뺐어요(skipped2025).
  • 공연이 적은 묶음은 참고만 하세요. 시작 시각별 묶음 가운데 n이 5보다 작은 것이 있어요.
  • 관객 구성은 추정이에요. 통신 자료로 추정한 생활인구에서 평소 인구를 뺀 값이라, 같은 날 다른 공연장 관객이 섞일 수 있어요.
  • 원본에서 찾은 문제와 처리 방법은 저장소의 web/data/data_quality.json에 있어요.
