# 웹앱 (1차: 데이터가 쌓이기 전 버전)

- `index.html` 관객 화면(모바일): 공연 선택 → 주차 선택지 비교(공원 안 / 걸어올 수 있는 곳 / 환승주차) → 주변 도로
- `operator.html` 운영자·기관 화면(PC): 그날 공연, 대응 수준, 출차 곡선(2024-07 참고), 도로 지도, 출구별 대응 표(2025 데이터 반영 예정), 기관 공유용 한 장 요약(인쇄/PDF)

## 실행
`run_web.bat` 더블클릭 → 브라우저에서 http://127.0.0.1:8000
(파일을 그냥 더블클릭해서 열면 데이터 파일을 못 읽어요. 꼭 bat으로 여세요.)

## 데이터
`data/*.json`은 `scripts/04_build_web_data.py`가 만든다. 원본이 바뀌면 다시 실행:
`python scripts\04_build_web_data.py`

최근 도로·주차 수집값은 공개 저장소(olpark-collector)의 `data/` 폴더에서 브라우저가 직접 읽는다.
(`assets/common.js`의 `CONFIG.collectorRepo`)

## 아직 비어 있는 것 (데이터가 쌓이면 채움)
- 공원 주차장 만차 예상 시각, 출구별 출차 예측 → 2025 입출차 다운로드 후
- 걸어올 수 있는 주차장의 귀가 이점 → 11/21·22, 11/27~29 공연일 실측 후
- 지하철 소요시간 → 역 간 소요시간 자료 확보 후
- 추천 문구는 지금 공연 좌석 규모 규칙(1만 석 이상 집중, 3천 석 이상 주의)
